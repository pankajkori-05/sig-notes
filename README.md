# SIG College Notes

Semester 1 study helper for M.Sc. Data Science and Spatial Analytics at SIG Pune.

## Pages

- Open `login.html` to sign in.
- After login you go to `index.html` (notes app).
- Opening `index.html` without a session redirects back to `login.html`.

## Login

- **Name** = username  
- **PRN** = password  
- First login creates your account in this browser. Later logins need the same Name + PRN.  
- **Logout** returns to `login.html`.

Upload notes for each subject. Everything is saved in this browser's localStorage.

## Study chat

On the notes page, open **Study chat** (bottom right). Ask about Semester 1 subjects or how to upload/login. Replies are local keyword help, not an AI API.
